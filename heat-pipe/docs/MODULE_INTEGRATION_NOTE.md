# 이상징후 탐지 모듈 연계 메모

- 정리일: 2026-10-03
- 목적: 외주 개발 시스템과 이상징후 탐지 모듈의 연계 협의 및 추후 모듈 개발 기준
- 상태: 과거 1차 협의안 — 입출력 배경자료로만 사용

2026-10-30 VTI 주간회의 결과 INT-002·005와 GIS/SHP·관로 매칭은 DaonH&S
범위에서 제외되었다. 현재 개발 범위와 API 기준은
[`heat-pipe-service/docs/INT_001_003_004_DEVELOPMENT_SCOPE.md`](../../heat-pipe-service/docs/INT_001_003_004_DEVELOPMENT_SCOPE.md)를 사용한다.

## 1. 데이터 연계 방식

외주 개발 시스템에서 ATT·ATG 파일을 저장한 후, 이상징후 탐지 모듈이 해당 파일에 접근하는 데 필요한 정보를 전달받는 방식으로 구성한다.

파일 자체를 요청 데이터에 포함할지 여부와 구체적인 호출 방식은 아직 확정하지 않는다. 기본 방향은 외주 개발 시스템이 파일을 보관하고, 모듈에는 저장 경로 또는 파일 식별자 등 접근 정보를 전달하는 것이다.

## 2. 모듈 입력

- 모니터링 데이터 ID
  - ATT·ATG 파일의 확장자를 제외한 공통 파일명을 사용한다.
- ATT 파일 접근 정보
- ATG 파일 접근 정보
- 분석 대상 구간
- 분석 ROI 정보

1차 이상징후 탐지 모듈 입력에서는 실영상 파일을 제외한다.

## 3. 분석 결과 출력

분석 결과는 JSON 형식으로 제공하며 다음 항목을 포함한다.

- 모니터링 데이터 ID
- 분석 성공·실패 상태
- 분석 대상 및 처리 정보
- 이상징후 후보 건수
- 열화상 내 ROI 좌표
- 후보 영역의 온도차
- 결과 열화상 이미지 경로

후보가 여러 건인 경우 후보별 결과를 배열 형태로 구성하는 것을 기본 방향으로 한다. 상세 JSON 스키마는 모듈 구현 및 외주 개발사와의 연계 협의 시 확정한다.

## 4. 결과 이미지

### 확정 사항 (2026-10-28)

이상징후 탐지 모듈에서 ROI 격자와 이상징후 후보 영역을 포함한 열화상 이미지를 직접 렌더링하여 제공한다.

- 이미지 포맷: PNG
- 이미지 해상도: 열화상 원본 기준 384×288

ROI 격자의 렌더링 책임은 이상징후 탐지 모듈에 있다. 포털에서 원본 열화상 이미지와 ROI 좌표를 조합하여 격자를 별도로 렌더링하는 방식은 기본 연동 방식으로 사용하지 않는다.

생성된 이미지는 협의된 저장공간에 파일로 저장하고, 분석 결과 JSON에는 이미지 파일의 접근 경로를 포함하는 방향으로 구성한다.

## 5. 개발 및 탑재 일정

- 외주 개발사의 개발 일정을 확인한 후 실제 모듈 탑재 및 테스트 일정을 협의한다.
- 이상징후 탐지 모듈 자체의 개발 일정과 외주 시스템에 모듈을 탑재하고 연동 테스트하는 일정은 별개로 관리한다.
- 내부 사정상 정상적인 모듈 개발 및 연동 지원 일정은 2026년 10월 31일 이후를 기준으로 검토한다.

## 6. 추후 확정할 사항

- 모듈 호출 방식(동기 또는 비동기)
- 외주 시스템 저장소와 모듈 사이의 파일 접근 방식
- JSON 상세 스키마와 후보별 필드
- 결과 이미지의 저장 위치, 파일명 규칙 및 접근 권한
- 오류 코드와 실패 결과 표현 방식
- 모듈 개발 완료 기준과 시스템 탑재·통합 테스트 완료 기준
