# T-05 실제 ATT·ATG 분석 검증 기록 (VTI 공유용)

- 정리일: 2026-11-04
- 실행일: 2026-11-02
- 입력: `20260813_132634.att` 875,667,464 bytes, 같은 이름의 `.atg` 151,552 bytes
- 입력 구성: 열화상 384×288, ATT 3,959프레임, ATG 3,885레코드
- 환경: 개발 PC의 WSL Ubuntu Docker, DaonH&S 분석 API·단일 분석 워커·SQLite·로컬 결과 저장소
- 검증 경로: INT-003 접수 → INT-004 상태·진행률 → INT-001 결과 JSON → 후보 PNG 조회

## 측정 결과

| 시험 | 분석 범위 | 완료 결과 | 측정 시간 | 결과 JSON |
|---|---|---|---|---|
| 초기 API 시험 | 첫 30프레임, **이전 기본 ROI** | `SUCCEEDED`, 후보 50건, 첫 PNG 조회 성공 | 별도 측정값 없음 | 별도 크기 측정값 없음 |
| 현재 기본 ROI, GPU Docker | 전체 3,959프레임, 2×3 격자 하단 가운데 칸 | `SUCCEEDED`, 후보 50건·PNG 50장 | 배치 분석 95.227초 | JSON Schema v0 통과 |

76,686 bytes는 최초 분석 워커가 저장한 내부 결과 JSON의 크기다. 별도 송부한 `int-001-real-result-20261102.json`은 같은 작업을 INT-001 응답 형태로 내보내면서 후보 이미지 경로를 API 조회 경로로 바꾼 파일이었다. B-08 반영 후 로컬에 보관한 실제 PNG 50장의 SHA-256과 크기를 이 샘플에 추가했으며, 갱신된 파일 크기는 **84,803 bytes**다. 최초 저장 JSON의 크기와 갱신된 샘플 크기는 측정 대상과 포함 필드가 달라 직접 비교할 수 없다.

갱신한 샘플 JSON의 `result_image.path`는 로컬 시험 작업의 조회 경로 예시다. VTI 시험 서버가 열리면 새 작업의 INT-001 응답에 포함된 경로로 PNG를 조회한다.

현재 기본 ROI는 384×288 영상의 `{x:128,y:144,width:128,height:144}`이다. 첫 30프레임 시험의 ROI는 수정 전 값이므로 운영 분석의 후보 수·시간 추정 기준으로 사용하지 않는다. 위 전체 프레임 시험은 현재 운영 기본 ROI와 동일한 설정이다.

**후보 50건은 현재 분석 설정의 `max_results=50` 상한이 적용된 반환 건수다.** 상한 적용 전 탐지 후보 총수나 향후 다른 알고리즘의 후보 수를 뜻하지 않는다. 이 값만으로 포털의 작업당 후보 1,000건 한도가 충분한지 확정할 수는 없다. 반환된 50건은 모두 PNG가 생성·검증되었으며, ATT 프레임 수와 ATG 레코드 수 차이는 `ATT_ATG_COUNT_MISMATCH` 경고로 기록됐다. 후보는 관로 이상 확정 판정이 아니다.

위 시간은 이 PC의 로컬 Docker 환경에서 측정했다. CPU·GPU의 배치 시간에는 작업 대기, 외부 네트워크 다운로드, VTI MinIO 전송 및 포털 처리 시간이 포함되지 않는다. URL 시험도 같은 PC의 모의 HTTPS 파일 서버를 사용했으며 실제 VTI MinIO 연동 시험은 아니다. 따라서 포털의 `QUEUED` 6시간·실행 3시간 한도는 임시값으로 두고, 시험 서버에서 VTI가 발급한 Presigned URL로 전체 파일을 처리한 뒤 다시 검토한다.
