# 실제 ATT·ATG 단일 작업 검증

> 이 30프레임 검증은 기본 ROI를 하단 가운데 격자 칸으로 수정하기 전의 기록이다. 현재 기본 ROI의 전체 프레임 결과는 [재검증 기록](REAL_DATA_CENTER_ROI_2026-11-02.md)을 참고한다.

- 실행일: 2026-11-02
- 입력: `E:\heatpipe\20260813\20260813_132634.att` (875,667,464 bytes), 같은 이름의 `.atg` (151,552 bytes)
- 방식: 원본 읽기 전용, 별도 임시 SQLite DB·결과 저장소, Bearer 인증을 적용한 API 호출
- 분석 구간: 첫 30프레임

## 확인 결과

| 항목 | 결과 |
|---|---|
| INT-003 접수 | HTTP 202, `QUEUED`, 작업 ID 반환 |
| 작업 실행 및 INT-004 | `SUCCEEDED`, 진행률 100%, 처리 프레임 30 |
| INT-001 결과 | HTTP 200, 후보 50건 반환 |
| 후보 PNG | 첫 후보 조회 HTTP 200, `image/png`, PNG 시그니처 확인 |
| 임시 작업 폴더 | 실행 후 제거 확인 |

이 검증은 로컬 공유 파일 입력을 사용했다. VTI의 Presigned GET URL, 네트워크 전송, 실제 MinIO 서버, 전체 3,959프레임 처리 시간은 검증 범위에 포함하지 않았다. 재현 명령은 [README](../README.md#테스트)를 참고한다.
