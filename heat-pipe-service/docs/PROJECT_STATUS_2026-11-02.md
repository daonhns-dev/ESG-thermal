# Heat Pipe Service 진행 현황

기준일: 2026-11-02. 이 문서는 **DaonH&S 분석 서비스**의 진행 상황을 요약한다. VTI 포털·GIS/SHP·INT-002·005는 이 저장소의 구현 범위가 아니다.

## 현재 위치

| 단계 | 상태 | 남은 확인 |
|---|---|---|
| INT-001·003·004 API, 작업 상태, Bearer 인증, 결과 JSON·PNG | 로컬 구현·테스트 완료 | VTI가 실제로 호출해 계약 확인 |
| 기존 이상탐지 알고리즘, 하단 가운데 ROI, ATT 온도 통계 | 실제 전체 파일로 실행 완료 | 차량 열점 등 후보 품질 검토 |
| CPU·GPU Docker | 로컬 전체 파일 검증 완료 | DaonH&S GPU 시험 서버에 배포·재검증 |
| 파일 URL 다운로드 | 로컬 서명 HTTPS URL로 실제 875MB ATT·ATG 검증 완료 | VTI MinIO의 실제 URL·네트워크·유효기간 확인 |
| Q15 연동 API 명세 | 초안 전달, VTI 검토 중 | 11월 4일 의견 수신 후 11월 6일 전달본 반영 |
| VTI 양측 연동 시험 | 시작 전 | 시험 서버 준비 후 실제 요청·상태·결과·오류 시나리오 확인 |

**완료된 단계는 로컬 구현과 로컬 실데이터 검증이다.** 최종 납품·연동 완료를 뜻하지 않는다. 현재 분석은 규칙·통계 기반 후보 탐지이며 학습된 AI 모델은 없다. GPU 경로는 기존 점수맵 계산을 빠르게 하는 구현이다. AI 모델 학습·적용은 2027년 상반기 후속 단계로 예상하며 현재 Q15 작업의 완료 조건에 포함하지 않는다.

## 확인된 근거

- 전체 테스트 23개 통과. 기존 결과 JSON Schema v0 유지.
- 실제 ATT 3,959프레임의 Docker API 작업에서 CPU·GPU 모두 후보 50건을 반환했고 주요 결과가 일치. GPU 배치 95.227초, CPU 배치 427.246초. [비교 기록](CPU_GPU_DOCKER_COMPARISON_2026-11-02.md).
- 로컬 모의 서명 HTTPS URL로 실제 875MB ATT·ATG 다운로드부터 GPU 결과·PNG 조회까지 완료. 크기 불일치, 허용되지 않은 주소, 만료 URL 오류도 확인. [기록](HTTPS_URL_LOCAL_TEST_2026-11-02.md).
- 로컬 GPU Docker 실행 절차와 검증 결과는 [GPU 분석 문서](GPU_ANALYSIS.md)에 있다.

## 남은 일의 순서

1. 현재 미커밋 상태인 URL 다운로드 검증 파일과 문서를 정리해 커밋·푸시한다.
2. 11월 4일 VTI의 Q15 의견을 받고 파일 전달·완료 확인·진행률·후보 ID 정책을 반영해 11월 6일 명세를 전달한다.
3. 개발 이사님과 GPU 시험 서버 준비일을 확인한다. **11월 9일 VTI 접속 가능한 엔드포인트 제공은 아직 확정되지 않았다.** 서버 일정에 맞춰 양측 시험일을 정한다.
4. 서버 준비 후 GPU Docker 배포, HTTPS API 주소, Bearer 키, VTI 파일 저장소 접근을 확인하고 VTI 백엔드의 정상·오류 작업을 함께 시험한다. 상세 항목은 [연동 시험 체크리스트](VTI_INTEGRATION_TEST_CHECKLIST.md)에 있다.

후보 품질은 VTI 실데이터 연동·인수 시험에서 함께 검토한다. 차량 열점 등 기존 관찰 사항은 [GPU 전체 검증 기록](REAL_DATA_GPU_DOCKER_2026-11-02.md)에 남겨두었다. AI 모델에 필요한 정답 데이터·평가 기준과 모델 개발은 2027년 상반기 후속 계획으로 다룬다.

현재 VTI 실제 MinIO URL, 시험 서버, VTI 백엔드 호출은 검증되지 않았다. 로컬 모의 URL 검증을 외부 연동 완료로 표기하지 않는다.
