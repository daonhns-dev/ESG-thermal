# 열수송관 이상 후보 탐지 진행 현황

2026년 11월 17일 기준. 통합 연구 계획의 10개 단계 중 **7개 단계에서 실행 또는 영상 검토 결과를 확보**했다. 차량 열원 분류는 시제품과 평가 자료를 마련했다. 영상 모델 연구와 최종 조합 채택은 후속 단계다. 7/10은 결과가 나온 단계의 수이며, 최종 알고리즘 완료율은 단계별 검증 범위가 달라 백분율로 산정하지 않았다.

| 단계 | 상태 |
|---|---|
| 1. 입력과 기준선 | ATT·ATG 14쌍 비교. 11쌍의 전체 구간이 유효했고, 3쌍의 대부분은 0값 프레임이었다. ATT와 ATG의 프레임 정렬은 별도 확인이 필요하다. |
| 2. 영상 판독 | 순위가 변한 후보 585개 중 75개의 열원 유형을 기록했다. |
| 3. 점수 개선 | MAD 대체값으로 점수가 과도하게 커지는 현상을 줄였다. ΔT·면적·지속성 조합은 여러 방식으로 비교했다. 차량 비중과 노면 후보 유지 여부를 확인 중이다. |
| 4. 추적 | 다섯 방식의 초기 18개와 인접 열원 12개를 판독했다. 누락 허용이 다른 열원으로 넘어간 사례가 있어 다음 독립 비교에는 현행 추적 조건을 사용한다. |
| 5. 선정 | 점수순, 10구간 순환, 영상상 가까운 후보의 중복 억제를 25·50·100건에서 비교했다. |
| 6. 비지도 재순위 | Isolation Forest와 LOF의 날짜 분리 비교를 실행했다. 열원 유형별 이득은 판독으로 평가해야 한다. |
| 7. 차량 열원 분류 | 평가 날짜를 빼고 판독된 46개 트랙으로 차량 순위를 낮췄다. 두 평가 파일에서 각 방식의 상위 50건을 모두 확인했으며 고유 후보 227개를 판독했다. 감점 0.05에서 E1 노면 후보 13건을 모두 유지했다. 같은 자료로 감점을 조정했으므로 새 촬영 회차에서 검증한다. |
| 8. 영상 모델 | 라벨이 확보되면 재구성·객체 탐지·시공간 모델을 비교할 계획이다. |
| 9. 처리 성능 | 로컬 360프레임에서 연속 읽기와 기울기 재사용의 출력 동일성을 확인했다. 시험 서버와 전체 실행 성능은 별도 검증 범위다. |
| 10. 최종 조합 | 개별 개선안의 평가 뒤 기존 기준선과 결합본을 비교한다. |

11월 18일 공유는 외장하드 실증 촬영의 현재 알고리즘 처리 결과를 중심으로 한다. 순위 실험과 열원 판독은 기존 8월 자료에 대한 연구 결과다.
